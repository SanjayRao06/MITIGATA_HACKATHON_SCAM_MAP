# Stitch design reference (P6)

Mobile screens exported from Google Stitch (2026-10-31). These are the **layout reference** for the
website in `server/web/`. Their **colours are not used**: Stitch drifted to a mint palette
(`#EDFDF4` background); the site uses our Sage & Cream palette (`docs/11-stitch-prompts.md`).

Changed on purpose when building the site:
- Accusing wording ("fraudulent", "cyber fraud", Hindi "धोखाधड़ी") replaced with "reported" / "scam" ([PRD §5] rule 3).
- Claims of being an official body ("India Civic Registry", "Ministry of Home Affairs", "verified by
  civic volunteers") removed; only the real 1930 helpline and cybercrime.gov.in link are kept.
- Profile/account icon removed (no login, [PRD §8] row 6).
- Made-up numbers replaced by live data from our API.
- Laptop layout designed from these mobile screens (no desktop export was provided).
