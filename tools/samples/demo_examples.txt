COMMUNITY SCAM MAP - SAMPLE REQUESTS FOR /docs
================================================
Where:  http://localhost:8000/docs   (or https://mitigata-hackathon-scam-map.onrender.com/docs)
How:    POST /reports -> Try it out -> paste ONE body below -> Execute -> read "Server response"
        GET /lookup   -> Try it out -> fill "type" and "value" -> Execute

RULES
- Send each report ONCE (each has its own report_id; the same report_id twice counts once).
- Times must be in the PAST (future -> 400). If you use this on another day, change the
  date in "occurred_at" / "reported_at" to that day (keep the time earlier than now).
- Start with:  POST /admin/reset  -> Execute
- On the LIVE server, finish with POST /admin/reset again.
